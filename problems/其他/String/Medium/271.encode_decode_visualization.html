LeetCode 271. Encode and Decode Strings Medium Python 3 String Design Two Pointers
📝 題目描述 (Problem)
設計一個演算法，將字串列表（List[str]）轉換為單一字串（Encode），並能將該字串無損還原為原列表（Decode）。
設計挑戰： 字串內部可能包含任何可能的 256 個 ASCII 字元（包含 #、空格、甚至無效字元），因此簡單的符號分割法會失效。
Example 1:
Input: ["neet", "code", "love", "you"]
Encoded: "4#neet4#code4#love3#you"
Output: ["neet", "code", "love", "you"]
Time Complexity O(N)
Space Complexity O(1)*
