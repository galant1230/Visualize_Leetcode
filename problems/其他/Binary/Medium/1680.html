📖 1680. Concatenation

題目敘述: 給定 n，將 1 到 n 的二進位串接，返回十進位值模 10^9+7。

範例 2: n=3, Output=27
"1" + "10" + "11" = "11011"

核心思路:
每當遇到 2 的冪次，位元長度加 1。使用 (ans << bit_length) | i 進行拼接，避免字串操作。

變數監控中心

ans: 0 | bit_length: 0
Current Binary State (ans):
class Solution:
def concatenatedBinary(self, n: int) -> int:
ans, bit_length = 0, 0
for i in range(1, n + 1):
if (i & (i - 1)) == 0:
bit_length += 1
ans = ((ans << bit_length) | i) % 1000000007
