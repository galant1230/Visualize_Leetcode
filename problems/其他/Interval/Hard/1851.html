1851. Minimum Interval

給你一個二維整數陣列 intervals，其中 intervals[i] = [left_i, right_i] 表示第 i 個區間。同時給你一個 queries 陣列。

第 j 個查詢的答案是包含 queries[j] 的 最小區間大小。如果不存在這樣的區間，答案為 -1。

規則： • 區間大小：right - left + 1
• 包含：left <= queries[j] <= right

Complexity Analysis

Time: O(N log N + M log M)

N 為區間數，M 為查詢數。需對 intervals 與 queries 進行排序，且每個區間最多進出 Heap 一次。

Space: O(N + M)

需額外儲存排序後的查詢索引，以及 Heap 最多存放 N 個區間。
