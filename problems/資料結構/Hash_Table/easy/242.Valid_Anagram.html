LeetCode 242. Valid Anagram Easy Hash Table String Sorting
📝 題目描述 (Problem)
給定兩個字串 s 和 t，撰寫一個函數來判斷 t 是否為 s 的字母異位詞（每個字母出現的次數完全相同）。
Example 1:
Input: s = "anagram", t = "nagaram"
Output: true
Example 2:
Input: s = "rat", t = "car"
Output: false
Time Complexity O(n)
Space Complexity O(k)
