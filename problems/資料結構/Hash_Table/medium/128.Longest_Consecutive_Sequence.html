LeetCode 128. Longest Consecutive Sequence Medium Array Hash Table Union Find
📝 題目描述與範例 (Examples)
給定一個未排序的整數陣列 nums，請找出最長連續數字序列的長度。演算法的時間複雜度必須為 O(n)。
Example 1:
Input: nums = [100, 4, 200, 1, 3, 2]
Output: 4
最長連續序列為 [1, 2, 3, 4]，長度為 4。
Time Complexity O(n)
Space Complexity O(n)
🐍 程式碼實作 READY
📊 執行狀態與視覺化 (State & Visualizer)
💡 解題思路
將所有數字存入 Hash Set。只對「序列開頭數字」（即 num - 1 不在 Set 中者）發起連續累加檢查，避免重複搜尋。
