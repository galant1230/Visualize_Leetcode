LeetCode 133. Clone Graph Medium
Presets:
📝 題目敘述 (Problem Statement)
給定一個無向連通圖中某個節點的引用，請返回該圖的 深拷貝 (Deep Copy)。
圖中的每個節點包含一個整數值 val 及一個包含其鄰居的列表 neighbors (List[Node])。
Example 1:
Input: adjList = [[2,4],[1,3],[2,4],[1,3]]
Output: [[2,4],[1,3],[2,4],[1,3]]
Time Complexity: O(V + E)
Space Complexity: O(V)
🐍 Python 程式碼解法 (DFS + Hash Map) READY
📚 Call Stack (DFS 遞迴歷程) Depth: 0
💡 解題思維 (DFS + Visited HashMap)
  1. HashMap 紀錄映射：使用 visited = {} 建立舊節點到新複製節點的對映 (old_node -> new_node)。
  2. 避免無窮迴圈：遍歷到舊節點時，若已在 visited 中，直接傳回對應的新節點（防止環形圖死鎖）。
  3. 遞迴複製鄰居：建立新節點後，遍歷其舊鄰居，將 dfs(neighbor) 的傳回值加入新節點的 neighbors。
🖼️ 深拷貝對比概念圖 (Clone Concepts Comparison)
ORIGINAL
Original Graph
題目給定的原始圖結構。
❌ SHALLOW
Return Same Graph
不能直接返回原圖節點 (舊指標)。
✅ DEEP COPY
Correct Clone
全新節點 + 保持完全相同的連接。
❌ WRONG EDGES
Messed Up Graph
雖建立新節點，但鄰居邊的連結錯誤。
