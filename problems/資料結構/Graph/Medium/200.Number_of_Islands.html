📝 題目描述與範例
給定一個 m x n 的二維網格 grid，代表陸地 ('1') 和水域 ('0') 的地圖。請計算並傳回網格中**島嶼的數量**。
島嶼被水域包圍，由相連（水平或垂直）的陸地單元格連接而成。
Time Complexity O(M * N)
Space Complexity O(M * N)
🐍 Python 程式碼解法 READY
📚 Call Stack (DFS 遞迴歷程) Depth: 0
💡 網格浸水法 (Sinking Island / DFS)
  1. Scan Grid：遍歷網格，當發現 grid[r][c] == '1' 時，島嶼數 +1。
  2. DFS Flood Fill：將該陸地浸水（改為 '0'），向上下左右延伸把整座相連島嶼「淹沒」。
  3. Base Cases：越界或遇到水域 grid[r][c] == '0' 時停止延伸 (剪枝)。
