743. 網路延遲時間

計算從節點 k 發送訊號，所有節點收到訊號所需的最短時間。

Example 1:

Input: times = [[2,1,1],[2,3,1],[3,4,1]], n = 4, k = 2

Output: 2

解題思路

1. 建立鄰接表存儲圖結構。

2. 使用 Min-Heap 維護當前最短路徑節點。

3. 透過 dist 字典記錄已確定的最短距離。

複雜度分析

Time: O(E log E)

Space: O(V + E)

class Solution:
  def networkDelayTime(self, times, n, k):
    graph = defaultdict(list)
    for u, v, w in times:
      graph[u].append((v, w))
    pq = [(0, k)]
    dist = {}
    while pq:
      time, u = heapq.heappop(pq)
      if u in dist: continue
      dist[u] = time
      if u in graph:
        for v, w in graph[u]:
          if v not in dist:
            heapq.heappush(pq, (time + w, v))
    return max(dist.values()) if len(dist) == n else -1
