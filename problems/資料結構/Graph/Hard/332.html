332. Reconstruct Itinerary

給定機票列表 tickets，其中 [from, to] 表示航班。

行程必須以 "JFK" 開頭。若有多個有效行程，回傳字典順序最小者。

必須使用所有機票一次且僅能使用一次。

Algorithm & Complexity

Hierholzer's DFS

利用 DFS 尋找歐拉通路。在回溯時記錄路徑，最後翻轉結果。

Time Complexity O(E log E)

主要開銷在於對鄰接表中的目的地進行排序。E 為機票數量。

Space Complexity O(V + E)

需要儲存圖結構（V 個機場與 E 條航線）以及 DFS 遞迴堆棧。

graph = collections.defaultdict(list)
for src, dst in sorted(tickets, reverse=True):
  graph[src].append(dst)
route = []
def dfs(curr):
  while graph[curr]:
    next_dest = graph[curr].pop()
    dfs(next_dest)
  route.append(curr)
dfs("JFK")
return route[::-1]
