CAR FLEET
SYSTEM READY

題目敘述

計算抵達終點時的獨立車隊數量。後車追上前車後會合併，且速度降至與前車一致。

完整測資 (IO)

TIME
O(N log N)
SPACE
O(N)

演算法狀態

Times List: []
Stack Top: None
ALGORITHM VISUALIZER TARGET: --
Stack: Fleet Times
0
Total Fleets
READY
class Solution:
  def carFleet(self, target, pos, spd):
    cars = sorted(zip(pos, spd), key=lambda x: x[0], rev=True)
    times = [(target - p) / s for p, s in cars]
    stack = []
    for t in times:
      if not stack or t > stack[-1]:
        stack.append(t)
    return len(stack)
