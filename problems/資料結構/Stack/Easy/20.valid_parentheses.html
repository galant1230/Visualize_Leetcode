LeetCode 20. Valid Parentheses Easy String Stack
📝 題目描述與範例 (Examples)
給定一個只包含 '(', ')', '{', '}', '[', ']' 的字串 s，判斷輸入字串是否有效。
有效字串需滿足：左括號必須用相同類型的右括號閉合，且必須以正確的順序閉合。
Example 1:
Input: s = "()[]{}"
Output: true
Example 2:
Input: s = "([)]"
Output: false
Time Complexity O(n)
Space Complexity O(n)
🐍 程式碼實作 READY
📊 執行狀態與視覺化 (State & Visualizer)
💡 解題思路 (Stack)
利用 Stack 後進先出 (LIFO) 的特性。遇到左括號就將對應的右括號 Push 入 Stack；遇到右括號時，檢查是否與 Stack 頂端相符並 Pop，否則無效。
