703. Kth Largest

找到資料流中排序後的第 k 大元素。

heapq.heapify(list)

將列表轉換成 Min-Heap。在 Python 中這是一個 **In-place** 操作，時間複雜度為 $O(N)$。

heapq.heappop(heap)

移除並回傳 Heap 中 **最小** 的元素。剩餘元素會自動重新排列維持 Heap 特性。

import heapq
class KthLargest:
 def __init__(self, k, nums):
  self.k = k
  self.heap = nums
  heapq.heapify(self.heap)
  while len(self.heap) > k:
   heapq.heappop(self.heap)

 def add(self, val):
  heapq.heappush(self.heap, val)
  if len(self.heap) > self.k:
   heapq.heappop(self.heap)
  return self.heap[0]
