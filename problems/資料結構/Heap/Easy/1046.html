1046. Last Stone Weight

每次挑選兩顆最重的石頭碰撞。若重量相等則皆消失，否則剩下兩者之差。

Max-Heap Trick

Python 只有 Min-Heap。我們將數值取 **負號** 存入，這樣最小的負數（原最大正數）就會在根節點。

heapq.heappush(h, -val)

碰撞後若有剩餘重量 $y-x$，記得取負號後再 Push 回去。

Input Stones

[2, 7, 4, 1, 8, 1]
Max-Heap Logic (Values inverted)
Step: 0
solution.py ● Python 3 
stones = [-s for s in stones]
heapq.heapify(stones)
while len(stones) > 1:
  x = heapq.heappop(stones)
  y = heapq.heappop(stones)
  if x != y:
    heapq.heappush(stones, x - y)
return -stones[0] if stones else 0
