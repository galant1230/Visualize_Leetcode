LeetCode 297. Serialize and Deserialize Binary Tree Hard
Presets:
📝 題目描述與複雜度
設計一個演算法將二元樹序列化 (Serialize) 為字串，並能將該字串反序列化 (Deserialize) 還原為原本的二元樹結構。
Time Complexity O(N)
Space Complexity O(N)
🐍 Python 程式碼解法選擇 READY
📚 Call Stack (系統呼叫堆疊) Depth: 0
💡 如何完美的序列化與反序列化二元樹？
  1. 標記空節點 (Null Symbol)：單靠前序遍歷無法唯一確定樹結構，必須顯式記錄 Null 節點（例如用 "#" 或 "N"）。
  2. 序列化 (Serialize)：前序 DFS 順序為 [根, 左子樹, 右子樹]。遇到 None 時寫入 "#"，並用逗號分隔成字串。
  3. 反序列化 (Deserialize)：將字串用逗號分割為陣列/佇列，利用佇列 **FIFO (先進先出)** 特性：
    • 彈出第一個元素作為 Root。
    • 若為 "#" 代表 None。
    • 否則建立節點，並依序遞迴建構 left 與 right。
