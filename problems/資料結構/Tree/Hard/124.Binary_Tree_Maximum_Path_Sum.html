LeetCode 124. Binary Tree Maximum Path Sum Hard
Presets:
📝 題目描述與複雜度
二元樹中的路徑被定義為一條鏈結序列，序列中相鄰節點之間需有邊連結。同一節點在同一條路徑中最多出現一次。計算並返回所有可能路徑中的最大路徑和。
Time Complexity O(N)
Space Complexity O(H)
🐍 Python 程式碼解法選擇 READY
📚 Call Stack (系統呼叫堆疊) Depth: 0
💡 如何推導出 Post-order DFS 公式？
  1. 理解路徑的特性：路徑可以「拱起」（同時包含左右子樹），但向上回傳給父節點時，只能選擇左或右其中一條分支，否則無法連成不重複的路徑。
  2. 捨棄負貢獻：如果左或右子樹帶來的路徑和為負數，不如不採納，因此取 max(0, left_gain)。
  3. 更新全域最大值 (拱形路徑)：以當前節點為頂點的最長路徑為：
    current_path = node.val + left_gain + right_gain
    用此值更新全域最大和 max_sum = max(max_sum, current_path)。
  4. 回傳給父節點 (單邊路徑)：傳給上一層父節點時，只能選一邊：
    return node.val + max(left_gain, right_gain)
