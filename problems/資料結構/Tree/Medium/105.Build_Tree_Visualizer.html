LeetCode 105. Construct Binary Tree from Preorder and Inorder Traversal Medium
Presets:
📝 題目描述與複雜度
給定兩個整數陣列 preorder 與 inorder，其中 preorder 是二元樹的前序走訪，inorder 是同一棵樹的中序走訪，請構造並返回該二元樹。
Time Complexity O(N²)
Space Complexity O(N²)
🐍 Python 程式碼解法選擇 READY
📚 Call Stack (系統呼叫堆疊) Depth: 0
💡 如何推導出陣列切片公式？
  1. 找根節點 (Root)：前序遍歷的規律是 [根節點, 左子樹..., 右子樹...]，因此 preorder[0] 一定是當前的根節點。
  2. 分割中序陣列 (Inorder)：中序遍歷的規律是 [左子樹..., 根節點, 右子樹...]。找出根節點在中序中的索引 divide_index = inorder.index(preorder[0])：
    • 左子樹中序範圍：inorder[:divide_index]（共 divide_index 個節點）
    • 右子樹中序範圍：inorder[divide_index + 1:]
  3. 推導前序陣列 (Preorder) 切片：因為左右子樹的節點總數量在前後序中必須完全一致：
    • 左子樹前序範圍：長度等於 divide_index，排除索引 0 的根節點後，即為 preorder[1 : divide_index + 1]。
    • 右子樹前序範圍：剩餘部分即為 preorder[divide_index + 1 :]。
