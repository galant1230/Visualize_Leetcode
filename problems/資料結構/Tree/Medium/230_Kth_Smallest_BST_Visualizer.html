📝 題目描述與範例
給定一個二元搜尋樹 (BST) 的根節點 root 和一個整數 k，請找出樹中第 k 小的節點值（1-indexed）。
BST 關鍵特性：中序走訪（Inorder Traversal: 左 -> 中 -> 右）產生的節點序列為嚴格遞增排序。

💡 解題思路說明
💡 中序走訪與 K 值遞減核心邏輯 (Inorder Logic)
k -= 1; if k == 0: return node.val
1. 左子樹優先 (Left Branch First)
遵循 BST 性質，先一路探底至最左小節點，確保處理順序嚴格由小到大。
2. 訪問節點與計數 (Visit & Count)
當「中」被訪問時計數器減 1（或加 1），剛好抵達第 $k$ 小時立刻記錄結果。
• 提前剪枝 (Early Exit)：找到答案後，後續的右子樹與未訪問節點皆無須繼續遞迴，省下大幅時間！
