LeetCode 212. Word Search II Hard
Presets:
📝 題目描述與複雜度
給定一個 m x n 的字元網格 board 和一個單字列表 words，找出所有同時存在於網格中的單字。
單字必須由相鄰（上下左右）的字母組成，同一個單格字母在同一個單字中不能重複使用。
Time Complexity O(M × N × 4^L)
Space Complexity O(W × L)
🐍 Python 程式碼解法選擇 READY
📚 Call Stack (DFS 網格地圖搜尋歷程) Depth: 0
💡 Trie (前綴樹) + DFS 核心最佳化技巧
  1. 將 Words 建為 Trie：不必對每個 Word 都做一次網格 DFS，而是以網格點為起點，順著 Trie 的分支往下找。
  2. 直接將單字存於末端節點 (word)：當找到單字時直接加入結果，不用再拼接字串。
  3. 強效剪枝 (Pruning)：找到單字後將該節點的單字標記清除；若某節點無任何子節點，直接從父節點將其刪除，避免重複無用的搜尋！
