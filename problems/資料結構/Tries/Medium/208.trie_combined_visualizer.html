📝 題目描述與複雜度
請實現一個 Trie (前綴樹 / 字典樹)，包含 insert、search 和 startsWith 三種方法：
• insert(word): 向字典樹插入字串。
• search(word): 如果字串在字典樹中，返回 true。
• startsWith(prefix): 如果存在任何以該前綴開頭的字串，返回 true。
Time Complexity O(L) per op
Space Complexity O(N × L)
🐍 Python 程式碼解法選擇 READY
📚 Call Stack (系統呼叫堆疊) Depth: 0
💡 Trie (前綴樹) 的核心運作機制
  1. 樹狀結構與共享前綴：每個節點代表一個字元。擁有相同前綴的單字（如 "app" 與 "apple"）會共享相同的樹狀路徑，節省空間。
  2. 結尾標記 (End of Word Flag)：必須用特殊標記（如 is_end = True 或 "#"）記錄某字元是否為完整單字的結尾。
  3. search vs startsWith 的差別：
    • startsWith: 只要能順利沿著路徑走完所有字元即傳回 True。
    • search: 除了走完字元，該終點節點必須標記為 is_end == True。
