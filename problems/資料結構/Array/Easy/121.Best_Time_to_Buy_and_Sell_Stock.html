LeetCode 121. Best Time to Buy and Sell Stock Easy Array Dynamic Programming Two Pointers
📝 題目描述與範例 (Description & Examples)
給定一個陣列 prices，第 i 個元素代表股票在第 i 天的價格。 你只能選擇某一天買入，並在未來的另一天賣出。請計算並傳回你能獲得的最大利潤。如果無法獲利，回傳 0。
Example 1:
Input: prices = [7,1,5,3,6,4]
Output: 5
Explanation: 在第 2 天 (價格 = 1) 買入，第 5 天 (價格 = 6) 賣出，利潤 = 6-1 = 5。
Time Complexity O(N)
Space Complexity O(1)
