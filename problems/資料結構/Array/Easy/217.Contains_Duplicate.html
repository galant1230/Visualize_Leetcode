LeetCode 217. Contains Duplicate Easy Array Hash Table Sorting
📝 題目描述與範例 (Examples)
給定一個整數陣列 nums，如果陣列中任何數值至少出現兩次，則回傳 true；如果所有元素都是唯一的，則回傳 false。
Example 1:
Input: nums = [1, 2, 3, 1]
Output: true
Time Complexity O(n)
Space Complexity O(n)
🐍 程式碼實作 READY
📊 執行狀態與視覺化 (State & Visualizer)
💡 解題思路
利用 HashSet 儲存已走訪過的數字。遍歷時若發現數字已存在集合中，代表有重複，回傳 true；若無則加入集合。
