LeetCode 1. Two Sum Easy Array Hash Table
📝 題目描述與範例 (Examples)
給定一個整數陣列 nums 和一個目標值 target，請找出陣列中相加等於目標值的兩個整數，並回傳它們的索引。
Example 1:
Input: nums = [2, 7, 11, 15], target = 9
Output: [0, 1]
Time Complexity O(n)
Space Complexity O(n)
🐍 程式碼實作 READY
📊 執行狀態與視覺化 (State & Visualizer)
💡 解題思路
利用 Hash Table 儲存已走訪過的數字與索引。遍歷時計算補數 `diff = target - num`，若補數已在表中則直接回傳解答。
