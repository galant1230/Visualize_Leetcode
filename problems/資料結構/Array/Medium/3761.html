鏡像對最小距離

Medium 雜湊表
找到 i < j 使得 rev(nums[i]) == nums[j]。返回所有對中最小的距離 |i - j|。

複雜度分析

O(N) 時間複雜度
O(N) 空間複雜度

解題思路詳解

1. 逆向思考：

當我們處於位置 j 時，我們想找的是先前某個位置 i，其反轉值恰好等於現在看到的數。因此，雜湊表的 Key 存的是「期待被看到的數」。

2. 貪婪更新距離：

為了獲得「最小」距離，我們在更新雜湊表時，永遠只保留「最後一次出現」的索引，因為這會使 i-j 盡可能小。
