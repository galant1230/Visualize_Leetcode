1878. Get Biggest Three Rhombus Sums in a Grid

Current Top 3 Distinct Sums:
思路解釋 (中心擴張法)：
1. 用雙層迴圈遍歷每個格子作為中心點 (r, c)。
2. 設置半徑 q 從 0 開始往外擴張。
3. 擴張條件：只要四個頂點都在網格內即可：
   - 上: (r-q, c) / 下: (r+q, c) / 左: (r, c-q) / 右: (r, c+q)
4. 邊界加總規律 (沿著四個方向走 q 步)：
   - 上到右: (r-q+i, c+i)
   - 右到下: (r+i, c+q-i)
   - 下到左: (r+q-i, c-i)
   - 左到上: (r-i, c-q+i)
5. 使用 set 去重並找出前三大。
