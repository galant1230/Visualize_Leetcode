3212. Equal Frequency of X and Y

尋找符合條件的子矩陣數量：(1) 左上角固定在 (0,0) (2) 'X' 的數量等於 'Y' 的數量 (3) 至少包含一個 'X'。

Example: grid = [["X","Y","."],["Y",".","."]] | Output: 3
Input Grid
prefixX (Count of 'X')
prefixY (Count of 'Y')
VALID SUBMATRICES
0
Ready to start...
解題思路：
1. 建立兩個前綴和陣列 prefixX 與 prefixY。
2. 當掃描到 (r, c) 時，計算從 (0,0) 到 (r,c) 的矩形內 X 與 Y 的總數。
3. 公式依然是：上 + 左 - 左上 + 當前格子是否為該字母。
4. 檢查條件：prefixX[r+1][c+1] == prefixY[r+1][c+1] 且 prefixX > 0。
