LeetCode 238. Product of Array Except Self Medium Python 3 Array Prefix Sum / Product
📝 題目描述 (Problem)
給定一個整數陣列 nums，回傳一個新陣列 res，其中 res[i] 等於 nums 中除了 nums[i] 之外所有元素的乘積。
進階要求： 請寫出時間複雜度為 O(N) 且不使用除法的演算法。
Example 1:
Input: nums = [1, 2, 3, 4]
Output: [24, 12, 8, 6]
Example 2:
Input: nums = [-1, 1, 0, -3, 3]
Output: [0, 0, 9, 0, 0]
Time Complexity O(N)
Space Complexity O(1)*
