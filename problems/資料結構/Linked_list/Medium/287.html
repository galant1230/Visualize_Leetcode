LeetCode #287

Find the Duplicate Number

Status: Ready

Problem Description

找出包含 n+1 個整數陣列中唯一的重複數字。數字範圍 [1, n]。

Immutable Array O(1) Space

Complexity Analysis

Time: O(n)
Space: O(1)

利用 Floyd's 判圈演算法。將陣列索引視為鏈結節點，值視為 Next 指針，重複值即為環的入口。
