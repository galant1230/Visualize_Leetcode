LeetCode 19. Remove Nth Node From End of List Medium Linked List Two Pointers
Presets:
📝 題目描述與範例
給定一個單向鏈表的頭節點 head，刪除倒數第 n 個節點，並返回鏈表的頭節點。
進階要求：你能否嘗試用一次掃描 (One-pass) 解決這道題？
Time Complexity O(N)
Space Complexity O(1)
🐍 Python 程式碼 READY
💡 解題思路：雙指標 + 虛擬頭節點
核心步驟 (Dummy + Two Pointers)：
1. 建立 Dummy Node：指向 head，避免邊界條件（如刪除頭節點）特判。
2. 拉開距離：讓 fast 指標先往前走 n + 1 步。
3. 同步移動：slow 與 fast 同時推進，當 fast 到達末端時，slow 剛好停在被刪除節點的前一個。
4. 修改指標：slow.next = slow.next.next 跳過刪除節點。
