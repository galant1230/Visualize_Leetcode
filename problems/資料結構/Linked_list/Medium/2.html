兩數相加 視覺化工具

題目敘述 (Problem)

給定兩個非空的鏈表，代表兩個非負整數。數字以逆序存儲，每個節點包含一個數字。將這兩個數字相加，並以鏈表形式回傳結果。

複雜度分析 (Complexity)

時間複雜度： O(max(m, n)) - m 與 n 為鏈表長度，需遍歷較長者一次。

空間複雜度： O(max(m, n)) - 新鏈表長度最多為較長者加一。

1. 迭代演算法 (Iteration)

  • 建立：一個 dummy 節點（哨兵）、指標 cur 指向它、整數 carry = 0。
  • 迴圈：當 l1, l2 或 carry 存在時持續進行。
  • 計算：讀取當前數值（不存在則補 0），sum = v1 + v2 + carry。
  • 更新：進位 carry = sum // 10，當前位 digit = sum % 10。
  • 移動：建立新節點接在 cur 後，將 l1, l2, cur 向前移動。
  • 回傳：dummy.next 即為結果鏈表首部。

2. 遞迴演算法 (Recursion)

  • 定義函數：add(l1, l2, carry)。
  • 終止條件：若 l1, l2 皆空且 carry 為 0，回傳 None。
  • 提取數值：獲取 v1, v2，計算總和 total = v1 + v2 + carry。
  • 計算當前：透過 divmod 取得新的進位與當前位。
  • 遞迴：以 l1.next, l2.next 及更新後的 carry 呼叫下一層。
  • 回傳：建立目前位節點，其 next 指向遞迴產生的後續鏈表。
