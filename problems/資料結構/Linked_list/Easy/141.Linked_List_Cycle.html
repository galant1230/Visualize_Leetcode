LeetCode 141. Linked List Cycle Easy Hash Table Linked List Two Pointers

📝 題目描述與範例 (Examples)
給定一個單向鏈表的頭節點 head，判斷鏈表中是否有環 (Cycle)。
若鏈表中存在某個節點，可以透過持續追蹤 next 指標再次到達該節點，則表示鏈表中存在環。
Example 1:
Input: head = [3, 2, 0, -4], pos = 1
Output: true (鏈表末端 -4 連回 index 1)
Time Complexity O(N)
Space Complexity O(1)
🐍 程式碼實作 (Floyd's Cycle Algorithm) READY
📊 執行狀態與視覺化 (State & Visualizer)
💡 解題思路：快慢指標法 (Tortoise & Hare)
1. 使用雙指標：slow 每次走 1 步，fast 每次走 2 步。
2. 若鏈表有環，fast 最終必然會在環內追上 (相遇) slow。
3. 若鏈表無環，fast 或 fast.next 會先遇到 null，結束搜尋。
