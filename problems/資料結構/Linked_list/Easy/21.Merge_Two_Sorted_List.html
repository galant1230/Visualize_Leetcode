LeetCode 21. Merge Two Sorted Lists Easy Linked List Two Pointers
📝 題目描述與範例 (Examples)
將兩個已排序的鏈結串列 list1 與 list2 合併為一個新的遞增排序串列，並回傳標頭。合併必須透過拼接現有節點完成。
Example 1:
Input: list1 = [1,2,4], list2 = [1,3,4]
Output: [1,1,2,3,4,4]
Example 2:
Input: list1 = [], list2 = []
Output: []
Time Complexity O(n + m)
Space Complexity O(1)
🐍 程式碼實作 READY
📊 執行狀態與視覺化 (State & Stage)
💡 解題思路 (Approach)
維護一個哨兵節點 dummy 做為起點，並使用 curr 指針記錄當前合併串列的尾端。比較 list1 與 list2 當前節點的值，將較小者接在 curr.next 後方並推進相應指標。當其中一方為空時，直接將另一方剩餘鏈結整體掛載。
