LeetCode 206. Reverse Linked List Easy Linked List Recursion
📝 題目描述與範例 (Examples)
給定一個單向鏈結串列的頭節點 head，請將該串列進行反轉，並回傳反轉後的頭節點。
Example 1:
Input: head = [1,2,3,4,5]
Output: [5,4,3,2,1]
Example 2:
Input: head = [1,2]
Output: [2,1]
Example 3:
Input: head = []
Output: []
Time Complexity O(n)
Space Complexity O(1)
