1888. Sliding Window 互動調試器

模擬輸入：s = "111000" (n=6)

target1：s = "01*n" (n=6)

target2：s = "10*n" (n=6)

⬇️
i: -
diff1: 0
diff2: 0
res (min): ∞
點擊下一步開始模擬...
for i in range(2 * n):
  if s2[i] != target1[i]: diff1 += 1
  if s2[i] != target2[i]: diff2 += 1
  if i >= n:
    if s2[i-n] != target1[i-n]: diff1 -= 1
    if s2[i-n] != target2[i-n]: diff2 -= 1
  if i >= n - 1: res = min(res, diff1, diff2)
