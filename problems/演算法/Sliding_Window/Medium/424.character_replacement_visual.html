LeetCode 424. Longest Repeating Character Replacement Medium Hash Table String Sliding Window
📝 題目描述與範例 (Description & Examples)
給定一個僅包含大寫英文字母的字串 s 以及一個整數 k。你可以選擇字串中的任意字元並將其替換為任何其他大寫英文字母，最多可執行 k 次。請回傳在執行上述操作後，包含相同字母的最長子字串長度。
Example 1:
Input: s = "AABABBA", k = 1
Output: 4
Explanation: 將索引 2 的 'B' 替換為 'A' 後，得到 "AAAA" (長度為 4)。
Time Complexity O(N)
Space Complexity O(26) ≈ O(1)
