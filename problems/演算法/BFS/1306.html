1306. Jump Game III

給定一個非負整數陣列 arr 與起始索引 start。當你在索引 i 時，可以跳到 i + arr[i] 或 i - arr[i]。請判斷是否能走訪到任何數值為 0 的索引。

Constraints:
  • 1 ≤ arr.length ≤ 5 * 10⁴
  • 0 ≤ arr[i] < arr.length
  • 0 ≤ start < arr.length

Complexity & Architecture

Time: O(N) Space: O(N)

藉由廣度優先搜尋 (BFS)，我們從起點向外逐層擴散。利用 visited 集合阻斷重複路徑，確保每個節點在最糟狀況下僅被推進 Queue 一次，完美避免死循環，將時間收斂在線性。
