LeetCode 125. Valid Palindrome Easy Two Pointers String
📝 題目描述與範例 (Examples)
在考慮所有大寫轉小寫字元，並移除所有非英數字元（alphanumeric）後，若該字串正著讀與反著讀皆相同，則該字串為一個迴文（Palindrome）。
Example 1:
Input: s = "A man, a plan, a canal: Panama"
Output: true
清理後: "amanaplanacanalpanama"
Example 2:
Input: s = "race a car"
Output: false
Time Complexity O(n)
Space Complexity O(1)

📊 執行狀態與視覺化 (State & Visualizer)
💡 解題思路 (Two Pointers)
使用左右指標 left 與 right。向內移動時過濾掉非英數字元，並比對轉換成小寫後的字元是否一致，達成原位（O(1) 空間）檢查。
