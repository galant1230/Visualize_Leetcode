LeetCode 15. 3Sum Medium Array Two Pointers Sorting
📝 題目描述與範例 (Examples)
給定一個整數陣列 nums，傳回所有滿足 i != j、i != k 且 j != k，並且 nums[i] + nums[j] + nums[k] == 0 的三元組 [nums[i], nums[j], nums[k]]。
解集合中不可包含重複的三元組。
Example 1:
Input: nums = [-1, 0, 1, 2, -1, -4]
Output: [[-1, -1, 2], [-1, 0, 1]]
Time Complexity O(n²)
Space Complexity O(1) / O(n)
🐍 程式碼實作 READY
📊 執行狀態與視覺化 (State & Visualizer)
💡 解題思路
1. 先將陣列進行升冪排序。
2. 固定外層指標 i，將剩餘範圍轉化為 Two Pointers 求 nums[l] + nums[r] == -nums[i]。
3. 遇到重複元素時利用 while 迴圈跳過，避免解答重複。
