LeetCode 11. Container With Most Water Medium Array Two Pointers Greedy
📝 題目描述與範例 (Description & Examples)
給定一個長度為 n 的整數陣列 height。有 n 條垂直線，第 i 條線的兩個端點分別為 (i, 0) 與 (i, height[i])。 找出其中的兩條線，使得它們與 x 軸構成的容器可以容納最多的水。
Example 1:
Input: height = [1,8,6,2,5,4,8,3,7]
Output: 49
Explanation: The vertical lines are represented by array [1,8,6,2,5,4,8,3,7]. In this case, the max area of water the container can contain is 49.
💡 解法核心思路 (Two Pointers & Greedy):
容器容量取決於 (r - l) * min(height[l], height[r])。使用雙指標從最寬處兩端向中間逼近，每次移動較短的那一側。因為如果移動較高側，寬度變小且高度最多維持原樣，面積必定變小；只有移動較矮側，才有可能找到更高的板子來提升總面積。
Time Complexity O(N)
Space Complexity O(1)
🐍 Python3 程式碼單步追蹤 READY
class Solution:
def maxArea(self, height: list[int]) -> int:
max_water = 0
l, r = 0, len(height) - 1
while l < r:
current_water = (r - l) * min(height[l], height[r])
max_water = max(max_water, current_water)
if height[l] < height[r]:
l += 1
else:
r -= 1
return max_water
📊 執行狀態與動態面板 (State Monitor)
Pointers (l, r) 0, 0
Heights (h[l], h[r]) 0, 0
Width (r - l) 0
Min Height 0
Current Area 0
Max Area 0
