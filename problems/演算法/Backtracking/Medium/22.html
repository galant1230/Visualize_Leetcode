22. Generate Parentheses

給定一個整數 $n$，請生成所有可能且「有效」的括號組合。

Example 1 n = 3
5 combinations
Example 2 n = 1
["()"]

Algorithm Logic

  • 1. 決策樹： 每一層代表放入一個括號，左或右。
  • 2. 左括號優先： 只要 o > 0（還有剩），就可以放 "("。
  • 3. 右括號限制： 只有當 o < c（左括號放得比右括號多）時，放 ")" 才是合法的。
  • 4. 終止條件： 當 o=0 且 c=0 時，代表字串構造完成。

Complexity Explains

Time: O(4ⁿ / √n)

由第 $n$ 個卡塔蘭數 (Catalan Number) 決定組合總數。

Space: O(n)

遞迴深度最大為 $2n$，因此空間複雜度為線性。
