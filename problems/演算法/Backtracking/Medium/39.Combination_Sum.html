📝 題目描述與詳細範例
給定一個無重複元素的整數陣列 candidates 和一個目標整數 target，找出所有和為 target 的唯一組合（可重複選取數字）。
Time Complexity O(N^(T/M))
Space Complexity O(T/M)
🐍 Python 程式碼解法 READY
📚 Call Stack (DFS 遞迴歷程) Depth: 0
💡 回溯法 (Backtracking) 核心三要素
  1. Choice (選擇)：從當前 start 索引開始選擇，避免產生重複組合。
  2. Base Cases (邊界)：target == 0 (成功存入) 或 target < 0 (剪枝返回)。
  3. Backtrack (撤銷)：執行 path.pop()，退回上一層試探其他可能。
