📝 題目描述與範例
給定一個 m x n 的字元矩陣 board 和一個字串 word。若 word 存在於網格中，傳回 true；否則傳回 false。
Time Complexity O(M * N * 3^L)
Space Complexity O(L)
🐍 Python 程式碼解法 READY
📚 Call Stack (DFS 遞迴歷程) Depth: 0
💡 回溯法 (Backtracking) 核心三要素
  1. Choice (選擇)：向右、下、左、上 4 個方向延伸試探下一個字元。
  2. Base Cases (邊界)：k == len(word) (匹配成功) 或 越界/字母不一致/已走訪 (剪枝)。
  3. Backtrack (撤銷)：恢復單元格字元 board[r][c] = temp，退回上一格。
