Subsets II

找出含重複元素數組的所有子集。核心挑戰在於如何「去重」。

Complexity Analysis

Time Complexity O(n · 2ⁿ)

共有 2ⁿ 個可能的子集，每個子集複製到結果集需 O(n)。

Space Complexity O(n)

遞迴深度最大為 n (Stack 空間)，不計入結果集。空間利用極其高效。

Logic Steps

  • ● Sort First: 排序後相同數字相鄰，是剪枝的前提。
  • ● Pruning: if i > start and nums[i] == nums[i-1]。這代表在同一層中，相同的數字只會被選一次。
