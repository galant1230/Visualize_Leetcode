Problem Description
困難 (Hard)
312. Burst Balloons
陣列 動態規劃
有 n 個氣球，索引從 0 到 n - 1。每個氣球標有數字 nums[i]。戳破氣球 i 可獲得：
nums[i-1] * nums[i] * nums[i+1]
邊界處理： 若 i-1 或 i+1 超出範圍，視為 1。需回傳明智戳破所有氣球後能獲得的 最大硬幣數量。
Algorithm Logic

1. 為什麼不能正向思考？

若正向枚舉「先戳破誰」，戳破後左右氣球會變相鄰，導致子問題不獨立。

2. 逆向枚舉：最後一個戳破

考慮在區間 (left, right) 中，氣球 k 是最後一個被戳破的。此時 left 和 right 氣球必定還在場。

3. 狀態定義

dfs(l, r) 表示戳破開區間 (l, r) 內最大收益：

dfs(l, k) + dfs(k, r) + nums[l]*nums[k]*nums[r]
