Stable Arrays II - O(N*M) 優化解析

進階挑戰：
當 zero, one 變大時，原本的 Σ 迴圈會太慢。我們需要觀察 $dp[i][j]$ 與 $dp[i-1][j]$ 的關係。
1. 優化思路 (Prefix Sum Optimization)
觀察結尾為 0 的轉移：
dp[i][j][0] = dp[i-1][j][0] + dp[i-1][j][1]
但這會包含「連續超過 limit 個 0」的情況。
具體來說，當我們從 dp[i-1][j] 轉移過來，如果我們減掉 dp[i-(limit+1)][j][1]，就剛好扣掉了那些「因為再加一個 0 就會破壞穩定性」的組合。
2. 優化後的轉移方程式
dp[i][j][0] = (dp[i-1][j][0] + dp[i-1][j][1] -非法項) % MOD
非法項 = dp[i - (limit + 1)][j][1] (若存在)
dp[i][j][1] = (dp[i][j-1][0] + dp[i][j-1][1] -非法項) % MOD
非法項 = dp[i][j - (limit + 1)][0] (若存在)
