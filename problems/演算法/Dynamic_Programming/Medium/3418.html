3418. Maximum Amount of Money Robot Can Earn

題目描述

機器人從 (0, 0) 出發到 (m-1, n-1)。
遇到負值扣錢，但擁有 2 次抵消強盜 的特殊能力（負值變 0）。

解題思路

1. 狀態定義

dp[i][j][k]：到達座標 (i, j) 時，使用了 k 次能力後的最高金幣數。

2. 轉移方程

不使用能力：繼承前一格同樣 k 狀態的最大值 + 當前格子金幣。

使用能力 (限 coins < 0)：繼承前一格 (k-1) 狀態的最大值，當前格視為 0。

限制條件

  • 網格大小最高 500 x 500
  • 能力使用上限：2 次
  • 結果可能為負數

動態矩陣演化

STEP: 0

三維 DP 狀態 (k=0 | k=1 | k=2)

完整解決方案 (Python)

class Solution:
def maximumAmount(self, coins):
m, n = len(coins), len(coins[0])
dp = [[[-float('inf')] * 3 for _ in range(n)] for _ in range(m)]
# 初始化起點 (0, 0) 的三種能力狀態
dp[0][0][0] = coins[0][0]
for k in range(1, 3):
dp[0][0][k] = max(dp[0][0][k-1], 0 if coins[0][0] < 0 else coins[0][0])
for i in range(m):
for j in range(n):
if i == 0 and j == 0: continue
for k in range(3):
# --- 不使用能力：從上方或左方轉移 ---
res = -float('inf')
if i > 0: res = max(res, dp[i-1][j][k])
if j > 0: res = max(res, dp[i][j-1][k])
dp[i][j][k] = res + coins[i][j]
# --- 使用能力：抵消當前強盜 (限負值) ---
if coins[i][j] < 0 and k > 0:
res_p = -float('inf')
if i > 0: res_p = max(res_p, dp[i-1][j][k-1])
if j > 0: res_p = max(res_p, dp[i][j-1][k-1])
dp[i][j][k] = max(dp[i][j][k], res_p)
return max(dp[m-1][n-1])
