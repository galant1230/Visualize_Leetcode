Stable Arrays I 思路解析

題目任務：
使用 zero 個 0 和 one 個 1 構造數組。限制條件是：連續的 0 或 1 的長度不能超過 limit。
1. 狀態定義 (DP State)
我們定義 dp[i][j][k] 為：
- i：已使用的 0 的數量
- j：已使用的 1 的數量
- k：最後一個放入的數字 (0 或 1)
2. 狀態轉移方程式 (Transition)
為了保證「穩定性」，如果目前最後放的是 0，則這組 0 之前必須接一個 1。
dp[i][j][0] = sum( dp[i-x][j][1] )
其中 x 範圍從 1 到 min(i, limit)
同理，如果目前最後放的是 1：
dp[i][j][1] = sum( dp[i][j-y][0] )
其中 y 範圍從 1 到 min(j, limit)
3. 基礎情況 (Base Cases)
當只有一種顏色且長度不超過 limit 時，只有 1 種排列法：
dp[i][0][0] = 1 (1 <= i <= limit)
dp[0][j][1] = 1 (1 <= j <= limit)
