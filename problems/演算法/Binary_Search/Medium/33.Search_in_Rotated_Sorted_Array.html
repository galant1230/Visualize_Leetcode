LeetCode 33. Search in Rotated Sorted Array Medium Array Binary Search
📝 題目描述與範例 (Examples)
已知經過旋轉的升序整數陣列 nums 與一個目標值 target。請在 O(log n) 時間複雜度內找出 target 在陣列中的索引，若不存在則回傳 -1。
Example 1:
Input: nums = [4,5,6,7,0,1,2], target = 0
Output: 4
Example 2:
Input: nums = [4,5,6,7,0,1,2], target = 3
Output: -1
Time Complexity O(n)
Space Complexity O(1)
