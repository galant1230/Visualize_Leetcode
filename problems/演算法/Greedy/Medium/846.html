846. Hand of Straights
Alice 有一些牌，她想要將這些牌重新分組，每一組必須包含 groupSize 張連續的牌。
• 1 <= hand.length <= 10^4
• 0 <= hand[i] <= 10^9
• 1 <= groupSize <= hand.length
Complexity Analysis
Time: O(N log N)
Space: O(N)
核心思路：先排序手牌。遍歷手牌時，若發現數字尚未被消耗（count > 0），則以此數字為起點，嘗試找尋後續連續的數字組成順子。
Test Cases
Example 1
Input: hand = [1,2,3,6,2,3,4,7,8], GS = 3
Output: true
Example 2

Output: false
