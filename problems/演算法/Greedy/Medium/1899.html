1899. Merge Triplets
給定一組 triplets 和一個 target。你可以選取任意數量的 triplet 並執行更新：res[i] = max(res[i], triplet[i])。判斷是否能得到 target。
• triplets[i].length == 3
• target.length == 3
• 1 <= triplets.length <= 10^5
Complexity Analysis
Time: O(N)
Space: O(1)
Greedy 思路：遍歷所有 triplet，如果一個 triplet 的三個數字都沒有超過 target 對應位置的數字，它就是「安全」的。我們將所有安全 triplet 的最大值合併，看最終是否等於 target。
